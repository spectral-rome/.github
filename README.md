# SPECTRAL organization defaults

This repository contains the default GitHub community files used across the `spectral-rome` organization.

The Issue templates under `.github/ISSUE_TEMPLATE/` define the common SPECTRAL research workflow for thesis and research-activity repositories:

- Research Question
- Research task
- Literature review
- Weekly update

Repositories may define their own local templates when a project requires different conventions.

The complete research workflow is documented in `spectral-rome/research-tutorial`.
