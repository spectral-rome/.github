# SPECTRAL organization defaults

This public repository contains only GitHub community files that are appropriate for every repository in the `spectral-rome` organization.

Thesis-specific Issue templates are deliberately **not** defined as organization-wide defaults. Applying them to every repository would also expose Weekly Update and Research Question templates in shared software repositories, where they do not belong.

Use [`spectral-rome/research-tutorial`](https://github.com/spectral-rome/research-tutorial) for the management model and Supervisor setup procedure. Copy only its `student-package/` contents into a student's research-activity repository.

Repository roles are configured locally:

- research-activity repositories use the Weekly Update, Research Task, Research Question, and Final Delivery templates from the research-activity template;
- shared repositories define their own bug, improvement, and Pull Request templates;
- project-specific repositories may add local templates when their workflow requires them.

Local repository configuration takes precedence over organization defaults.
